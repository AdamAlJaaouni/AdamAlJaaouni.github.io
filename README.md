# Adam Al Jaaouni Portfolio (React + GitHub Pages)

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to GitHub Pages

```bash
npm run deploy
```

This project is configured with:

- Vite base path: `/AdamAlJaaouni.github.io/`
- Deploy script: `gh-pages -d dist`
